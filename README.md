# VideoRSI — supplementary website

Open `index.html` in a recent browser (Chrome, Edge, Firefox or Safari).
Everything is local: the page loads no external resources.

- The short film at the top has sound; press "Play with sound".
- The looping clips are silent and start as they scroll into view.

To view it after downloading: click **Code → Download ZIP**, unzip, and open `index.html`.
